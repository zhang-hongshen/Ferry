# S3

Source: [`Packages/FerryStorage/Sources/S3Storage/`](../../Packages/FerryStorage/Sources/S3Storage/).

## Settings
Endpoint (empty means AWS; a scheme or path in the field is ignored), Region (default `us-east-1`),
Access Key ID, Secret Access Key (Keychain), Use HTTPS, Path-Style Access, Initial Path
(for example `/my-bucket/photos`).

Plain HTTP works only for local network hosts; see [Architecture](../Architecture.md#plain-http).

Local MinIO: Endpoint `localhost:9000`, Use HTTPS off, Path-Style Access on, root user and password as
the access key pair.

## Behavior
- **Addressing**: virtual-hosted (`bucket.host`) by default; path-style when enabled, or when the bucket
  name is not DNS-compatible (uppercase, underscores, or dots over HTTPS).
- **Regions**: a redirect or `AuthorizationHeaderMalformed` response carrying the bucket's region is
  retried once with that region, which is then cached per bucket.
- **Listing**: the root lists buckets; below it ListObjectsV2 with `delimiter=/` and `encoding-type=url`,
  1000 keys per page, streamed to the table page by page. Zero-byte `prefix/` markers are hidden.
- **Folders**: creating a folder writes a `prefix/` marker. When deleting or moving out the last item of a
  folder, a marker is written so the folder stays, as on a file system.
- **Delete**: permanent. Every version and delete marker of the file, or of every key below a folder's
  prefix, is listed with ListObjectVersions and removed with DeleteObjects (1000 per request,
  `Content-MD5`). Services or credentials without ListObjectVersions fall back to deleting current keys.
  Deleting a bucket from the browser empties it first.
- **Copy / move / rename**: CopyObject (UploadPartCopy in 512 MiB parts above 5 GiB); move is copy then delete.
- **Upload**: one PUT below 16 MiB; otherwise multipart with at least 8 MiB parts (≤ 10,000 parts), four
  in parallel, three attempts per part. The upload ID is the resume token; on resume, ListParts skips
  finished parts. Cancelling a transfer aborts the multipart upload.
- **Download**: 8 MiB ranged GETs with `If-Match`; the ETag is the resume token, so a changed object
  restarts from the beginning.
- **Metadata**: HEAD shows Content-Type, Cache-Control, Content-Disposition, Content-Encoding, ETag,
  storage class, and `x-amz-meta-*`. Saving copies the object onto itself with `REPLACE`. Custom names and
  values must be ASCII; objects above 5 GiB cannot be updated this way.
- **Sharing**: presigned GET links valid for 1 hour, 1 day, or 7 days (the SigV4 maximum).
- **Buckets**: created with a `LocationConstraint` outside `us-east-1`. Deleting a non-empty bucket from the
  sidebar asks again, then deletes all objects and versions first.
